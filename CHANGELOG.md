# CHANGELOG

Все значимые изменения в проекте CallNotifier документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [1.2.0] - 2026-10-12

### Добавлено
- **Словарь произношений и ударений**:
  - Таблица `pronunciation` в БД (`source`, `replacement`, `kind`).
  - CRUD через админку (таб «🔤 Словарь TTS»).
  - Автомиграция из старого хардкода (`LATIN_ABBR_DICT`, `STRESS_DICTIONARY`).
  - Применяется мгновенно — TTS перечитывает словарь при изменении.
  - Регистронезависимо для обоих типов (`replace`, `stress`).
- **Шаблоны TTS** для новых вызовов и напоминаний:
  - Таблица `tts_templates` в БД (`type`, `new_call_template`, `reminder_template`).
  - Визуальный редактор в админке (таб «📝 Шаблоны TTS»).
  - Плейсхолдеры: `{name}`, `{equipment}`, `{info}`, `{info_part}`, `{type}`, `{type_desc}`.
  - Превью на лету с тестовыми данными.
  - Кнопки быстрой вставки плейсхолдеров в активное поле.
  - Кнопка «Сбросить к дефолтному».
- **Выбор голоса Silero** (таб «🎙 Настройки TTS»):
  - 5 голосов: `xenia`, `aidar`, `baya`, `kseniya`, `eugene`.
  - Хранение в `config_server.json` (секция `tts.speaker`).
  - Применяется мгновенно, переживает перезапуск сервера.
- **Кнопка «Очистить кэш TTS»** — удаление всех WAV из `audio_cache/`.
- **Дефолтные шаблоны TTS включают `{info_part}`** — комментарий озвучивается по умолчанию.

### Исправлено
- **Дублирование вызовов** в `/api/v1/sync` — в `_process_server_data` было два подряд `result_calls.append(call)`. Оставлен один.
- **`render_template` — порядок подстановки**: `{info_part}` обрабатывается до `{info}`, чтобы не было конфликта.
- **Чистка пунктуации в шаблонах**: убираются висячие запятые и пробелы перед знаками препинания (`re.sub`).

### Изменено
- **`config_server.json`**: добавлена секция `tts` (`{"speaker": "xenia"}`).
- **`tts_service.py`**: `TTSService.__init__` принимает `config`, читает `tts.speaker`.
- **`server.py`**: `TTSService(db=db, config=config)` — передаётся ссылка на конфиг.

### Совместимость
- **Python:** 3.11.9
- **PyInstaller:** 6.22.3
- **Сервер и клиент:** минорные версии в пределах `1.x.x` совместимы.
- **Миграция:** словарь произношений и шаблоны TTS автоматически создаются при первом запуске сервера (таблицы + дефолтные значения).

## [1.1.0] - 2026-10-07

### Добавлено
- **Механизм версий клиента**: `GET /api/v1/version`, `server_version` в `/api/v1/sync`,
  бейдж «🔔 Доступно обновление» в хедере клиента.
- **Пер-клиентские напоминания вызовов**: трекер `_last_reminder_sent[(client_id, external_id)]`,
  идентификация клиента через заголовок `X-Client-Id` (`hostname-username`).
- **Пер-клиентские складские алерты**: `get_pending_alerts(client_id)` с изоляцией
  `_sent_by_client`.
- **Полный CRUD по складам в админке**: правка `name`, `capacity`, `orange_threshold`,
  `red_threshold`, `repeat_interval_min`, `current_value`.
- **Скрытие служебного типа `warehouse`** в UI админки (табы «Типы вызовов» и «Создать вызов»).
- **Полное скрытие блока складов** на клиенте при снятой галочке `warehouse` в F1.
- **Аудио-фильтр складов**: при снятой галочке клиент не получает ни алерты, ни визуализацию.
- **Автоинициализация статуса склада** при старте сервера, если склад уже в красной зоне.
- **Отложенная генерация алерта** в `_check_all`, если `_last_filename` ещё не создан.

### Изменено
- **Финальная вычистка рудиментов клиента**:
  - Удалена секция `audio` из `config_client.json`.
  - Удалён ползунок громкости и поле «Звуковой сигнал» из F1.
  - `default_beep.wav` больше не пакуется в `.exe` (остаётся на сервере).
- **Сборка `.exe`**: убран `--add-data "default_beep.wav;."`.
- **Устойчивость цикла синхронизации**: экспоненциальный backoff (5→10→20→30 сек),
  разделённые `except` для timeout / connection / HTTP / JSON.
- **Расположение бейджа обновления**: перенесён в правый фрейм хедера (под часами),
  чтобы не перекрывать заголовок.

### Удалено
- Старый GET-маршрут `/api/admin/close/<external_id>` (заменён на `POST /admin/api/calls/<id>/close`).
- Рудиментный `admin_password` из `config.json` (перенесён в `config_admin.json`).
- Файлы артефактов: `notifier.log` (общий), `notifier_dump.log`.

### Исправлено
- **Гонка напоминаний при нескольких клиентах**: каждый клиент получает напоминания независимо.
- **«Съедание» складских алертов первым клиентом** (было `get_pending_alerts()`, стало `get_pending_alerts(client_id)`).
- **Залипание алертов в очереди**: добавлен `_forget_sent_for_all(filename)` при добавлении в `_pending`.
- **Статус склада «Норма» при старте**, если склад уже превышал порог.
- **Каскадное проигрывание алертов** при возврате галочки: `register_client_activity` синхронизирует трекер.
- **Потеря логов в `.exe`**: `logger.py` узнаёт `.exe` по имени `callnotifierclient.exe`.
- **Ошибка `AttributeError` при отсутствии `self._latest_download_url`** до вызова callback.

### Совместимость
- **Python:** 3.11.9
- **PyInstaller:** 6.22.3 (для сборки клиента)
- **Сервер и клиент:** минорные версии в пределах `1.x.x` совместимы.

## [1.0.0] - 2026-09-30

Первичный релиз после разделения монолита на клиент-серверную архитектуру.

### Добавлено
- Разделение на `server.py` и `client.py`.
- Flask-сервер с `/api/v1/incoming`, `/api/v1/sync`, `/api/v1/audio/<filename>`.
- Silero TTS v5.5 с асинхронной генерацией.
- Менеджер складов с разделением на мгновенные и интервальные алерты.
- Веб-админка `/admin` с 5 табами.
- Полноэкранный Tkinter-клиент с анимацией пульсации.
- Автомиграция конфигов: `config.json` → `config_client.json` + `config_server.json`.
- Разделение логов: `notifier_server.log` / `notifier_client.log`.
