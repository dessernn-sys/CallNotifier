Словарь произношений и ударений

Замена — принудительная подмена текста для TTS (например, латиница → кириллица: Bobst → Бобст).
Ударение — расстановка ударения через + перед ударной гласной (например, иванов → ива+нов).
Поиск слов выполняется без учёта регистра. Изменения применяются мгновенно.
