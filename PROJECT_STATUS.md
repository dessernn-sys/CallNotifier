# PROJECT_STATUS.md

## 📊 Текущий статус проекта: **CallNotifier v.1.4.2**
* **Дата фиксации:** 15 октября 2026 г.
* **Архитектурный паттерн:** Распределённая клиент-серверная система (Backend-агностик, легковесный локальный GUI-клиент, веб-админка сервера). Конфигурации клиента и сервера полностью разделены.
* **Текущее состояние:** **Стабильная работа в поле**. Система развёрнута на рабочих местах, отработала несколько суток без сбоев. Реализованы расширенные настройки TTS (словарь, шаблоны, голос).
Реализовано **автообновление клиента** (`client_updater.py`): фоновая проверка версии, диалог + прогресс-бар, sha256, batch-замена `.exe`, бейдж «доступно обновление» в хедере.

## 🏗️ 1. Архитектурная карта и связи модулей

### 🖥️ Серверная часть
*   **`server.py`** — точка входа. Инициализирует `ServerConfig`, `AdminConfig`, БД, `TTSService(db=db, config=config)`, фоновые менеджеры.
*   **`database.py`** — SQLite-хранилище. Таблицы: `calls`, `types`, `warehouses`, `pronunciation`, `tts_templates`.
*   **`tts_service.py`** — Silero TTS v5.5 + управление словарём произношений, шаблонами и голосом.
*   **`warehouse_manager.py`** — фоновый мониторинг складов, per-client выдача алертов.
*   **`http_server.py`** — Flask API + веб-админка (8 табов).
*   **`config_server.json`** — `http_server`, `display.cache_ttl_days`, `warehouse`, `tts.speaker`.
*   **`config_admin.json`** — пароли админки и диспетчера.

### 💻 Клиентская часть
*   **`client.py`** — точка входа.
*   **`client_updater.py`** — автообновление клиента (проверка версии, скачивание, batch-замена).
*   **`audio.py`** — AudioManager. Опрос раз в 5 сек, устойчивость к сбоям, `X-Client-Id`.
*   **`gui/main_window.py`** — Tkinter GUI, карточки вызовов, бейдж обновления.
*   **`gui/dialogs.py`** — F1: IP/порт, TTL, фильтр типов.
*   **`config_client.json`** — клиентский конфиг.

### 🌐 Веб-админка (`static/admin/`)
8 табов: **Дашборд, Создать вызов, Типы вызовов, Шаблоны TTS, Склады, Словарь TTS, Настройки TTS, Логи**.

### 📦 Релизы клиента (`static/client/`)
`CallNotifierClient-<version>.exe` + sha256.

## 🧩 3. Реализованные фичи (справочник)

### Веб-админка (8 табов)
*   **Дашборд** — статус подсистем, активные вызовы, автообновление 5 сек.
*   **Создать вызов** — ручная эмуляция АСистем.
*   **Типы вызовов** — CRUD.
*   **Шаблоны TTS** — визуальный редактор текстов озвучки.
*   **Склады** — CRUD + ручное значение + форс-проверка.
*   **Словарь TTS** — CRUD произношений и ударений.
*   **Настройки TTS** — выбор голоса + очистка кэша.
*   **Логи** — хвост, живой поток, скачивание.

### Клиент `.exe`
*   Сборка через PyInstaller 6.22.3 (onefile, windowed).
*   Хранение: конфиг рядом с `.exe`, кэш и логи — в `%APPDATA%\CallNotifier\`.
*   Бейдж обновления в хедере.
*   F1: сервер, TTL, фильтр типов.

### Автообновление клиента
*   Фоновая проверка `GET /api/v1/version` (старт + раз в 6 часов).
*   Диалог подтверждения + прогресс-бар скачивания.
*   Headless-режим (без диалога).
*   sha256-проверка, retry (до 3 попыток).
*   Batch-замена `.exe` с резервной копией `.exe.old`.
*   Бейдж «🔔 Доступно обновление» в хедере.
*   Диагностика в `%APPDATA%\CallNotifier\update\update.log`.

### Фильтр типов вызовов (F1)
*   `?types=` в sync.
*   Складские алерты и визуализация отключаются вместе с галочкой.

### Словарь произношений и ударений
*   Хранение в БД.
*   Замена латиницы (`Bobst → Бобст`) и аббревиатур (`XL → ИксЭль`).
*   Ударения через `+` (`иванов → ива+нов`).
*   Регистронезависимо.
*   Мгновенное применение.

### Шаблоны TTS
*   Отдельные шаблоны для нового вызова и для напоминания.
*   Плейсхолдеры: `{name}`, `{equipment}`, `{info}`, `{info_part}`, `{type}`, `{type_desc}`.
*   Пустой шаблон → используется дефолтный.
*   Превью на лету.

### Голоса Silero
*   `xenia`, `aidar`, `baya`, `kseniya`, `eugene`.
*   Хранение в `config_server.json → tts.speaker`.
*   Смена мгновенная, переживает перезапуск.
*   Кнопка очистки кэша (все WAV удаляются, генерируются заново).

## 📌 6. Важные заметки

### `.exe`-сборка

PyInstaller распаковывает ресурсы в `%TEMP%\_MEIxxxxxx`. Путь через `__file__` указывает туда, запись провалится:

```python
if getattr(sys, 'frozen', False):
    base_path = sys._MEIPASS
else:
    base_path = os.path.dirname(os.path.abspath(__file__))
